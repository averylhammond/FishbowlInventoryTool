# What's New

Each release's changes, newest first. The application shows the sections you have not
seen yet the first time you open it after an update, and Help -> What's New brings this
back at any time.

## 2.3.0

- **Patch notes.** After an update, the application now opens with a summary of what
  changed. Skip a release or two and you will see everything you missed, not just the
  most recent version. Help -> What's New shows these notes whenever you want them.

## 2.2.1

- Fixed the application failing to reopen after an in-app update installed successfully.

## 2.2.0

- **Update and Restart.** When a new version is available, the update window can now
  download and install it for you and reopen the application when it is done. Exit and
  Update, which opens the download page in your browser, is still there if you prefer it.
- Added View -> Spreadsheets, so the reports you have generated can be browsed from
  inside the application.

## 2.1.0

- **Your settings are remembered.** Theme, font, font size, window size and position,
  and which report columns you had checked all come back the way you left them.
- Added hover text to the buttons and to every column checkbox, so the report's column
  names explain themselves.

## 2.0.1

- The application now checks for a newer version when it starts, and tells you if one is
  available. Help -> Check for Updates runs the same check on demand.

## 2.0.0

- **A rebuilt interface.** New look, a menu bar, selectable color themes and fonts, and
  an About window showing the version you are running.
- Added View -> Results Log, which opens the processing log without leaving the
  application.
- Numbers in the generated spreadsheet are now real numbers rather than text, so Excel
  will sort and total them.
- The parser no longer shifts a row's values into the wrong columns when the report
  leaves a column blank.
